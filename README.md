# Mobile Stock Market App UI/UX Design

## About the Project

This project showcases a mobile stock market application UI/UX design created using Figma. It focuses on delivering a clean, modern, and user-friendly interface for users to explore stock market information and manage their investments.

## Tools Used

- Figma

## Key Features

- Clean and user-friendly interface
- Stock market dashboard
- Stock price and market information
- Investment portfolio overview
- Transaction screens
- Settings screen
- Intuitive navigation
